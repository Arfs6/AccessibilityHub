Accessibility Hub

Accessibility Hub is a website that aims to make information on accessibility easily available online. It tries to achieve this by:

  1. Creating a platform for users to review tools.
  2. Creating a platform for discussion on accessibility related topics.

Reviews

The reviews feature aims to collect accessibility related information about a tool in a single page. This information will be gotten from users of Accessibility Hub. This will make getting information on the accessibility of a tool straight forward depending on the number and quality of info supplied by the community. This is going to be very useful for both users of tools and creators that are concerned with accessibility.

Discussions

Unlike reviews, discussions aren't tied to any tool. They provide a platform where topics on accessibility can be discussed, including general topics, recommendations, suggestions, and questions. As these pages are indexed by search engines, visitors can search for solutions to their accessibility problems and find useful information.
